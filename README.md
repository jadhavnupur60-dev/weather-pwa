# PWA Weather Widget

A Progressive Web App (PWA) weather widget built with HTML, CSS, JavaScript, and Service Workers featuring offline caching support and a custom install prompt.

## Features
- **Weather Information:** Displays current temperature and windspeed fetched from Open-Meteo API.
- **Offline Support:** Caches static assets and API responses using Service Workers (`sw.js`).
- **Installable PWA:** Configured with `manifest.json` for installation on mobile and desktop devices.
- **Responsive Design:** Clean, modern UI styled with custom CSS.
